# GPS Attendance Tracker

Starter workspace for a GPS-based attendance tracking system built with:

- Flutter Android app
- PHP REST APIs
- MySQL database
- PHP admin panel

## Project Structure

```text
mobile_app/
backend_api/
admin_panel/
database/
docs/
```

Planning documents live in `docs/`:

- `requirements.md`
- `api-endpoints.md`
- `database-design.md`
- `development-roadmap.md`
GPS-based attendance tracking app for village teaching centres.


Tech Stack:
- Flutter Android App
- PHP REST APIs
- MySQL Database
- PHP Admin Panel
- GoDaddy Linux Hosting / cPanel
